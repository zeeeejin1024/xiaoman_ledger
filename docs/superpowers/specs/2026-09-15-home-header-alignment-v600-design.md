# 小满记账 6.0 首页头部对齐设计

**目标：** 修正首页品牌区排版，让 Logo 与固定标题“小满记账”处于同一水平视觉轴，自定义话语及“更改”成为标题下方的独立编辑行。

**布局：** `HomeHeader` 使用左侧内容区加右侧设置入口。左侧第一行固定高度 38dp，依次为 38dp Logo、8dp 间距和品牌标题，Logo 与标题中心点垂直偏差不超过 1dp；第二行从标题左边缘开始，显示最多 16 个 Unicode 字符的自定义话语和“更改”。设置图标保持 24dp，编辑与设置命中范围保持至少 48dp。

**行为：** 点击标题或话语不进入编辑，只有“更改”触发弹窗；保存失败保留弹窗，成功才关闭。版本同步更新为 `6.0.0+19`，Android 构建后覆盖安装，不清除应用数据。

**验收：** Widget 几何测试验证 Logo/标题中心同线、自定义行在其下方；版本测试验证两个版本源；完整测试、release 构建、aapt、签名、SHA-256 和 Android 16 实机截图/交互均通过。
