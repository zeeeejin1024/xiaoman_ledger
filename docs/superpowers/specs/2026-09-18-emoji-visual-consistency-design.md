# 小满记账 Emoji 视觉统一设计

## 目标

降低装饰性 Emoji 带来的幼稚感和跨设备显示差异，让报告与首次引导页统一使用应用现有的 Material Rounded 图标语言，同时保留分类 Emoji 的快速识别价值。

## 范围

- 首次引导页：三枚大型 Emoji 替换为带主题色背景的 Material Rounded 图标。
- 月度报告：评分 Emoji 替换为根据结余状态变化的图标。
- 省钱周报：总结文案中的庆祝 Emoji 改为克制的纯文字。
- 用户状态：预设状态去掉 Emoji，仅保留清晰的中文状态文字。
- 分类、用户自定义分类、存钱目标 Emoji：保留，因为它们承担分类识别或用户自定义功能。

## 视觉规则

- 图标统一使用 Flutter 内置 `Icons.*_rounded`，不增加依赖。
- 引导页图标尺寸 48，置于 104×104 的圆角容器中，使用当前页面主题色的浅色背景。
- 月报状态图标尺寸 34，保持现有评分圆形容器和信息层级。
- 文案不使用装饰性 Emoji 表达成功、警告或鼓励，交由图标、颜色和文字共同表达。

## 兼容与迁移

已有用户保存的带 Emoji 状态不强制改写，避免破坏用户数据；只有新的预设状态不再带 Emoji。分类及存钱目标数据结构保持不变。

## 验证

- 静态测试确认装饰性页面源码不再含目标 Emoji。
- 保留分类 Emoji 的现有选择测试。
- 运行报告、引导页和版本测试。
- 构建 Release APK，并在 Android 16 实机覆盖安装确认版本。
