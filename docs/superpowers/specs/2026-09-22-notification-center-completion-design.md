# 通知中心完善设计

## 目标

让通知中心从“状态展示”升级为可配置、可验证、可恢复的 Android 本地提醒中心。

## 范围

- 每日记账提醒：开关、时间选择、未记账时才触发。
- 省钱周报：开关、星期、时间。
- 月度报告：开关、日期（1-28 日）、时间。
- 预算提醒：开关，沿用 80%/100% 阈值。
- 优惠提醒：开关、时间，沿用后端优惠数据。
- 生活费提醒：沿用预算提醒通道和去重规则，在现有生活费业务触发。
- 通知诊断：权限、排期数量、立即通知、15 秒定时通知。
- Android 重启/升级恢复、通知点击跳转、权限拒绝后的可恢复状态。

## 设计

`NotificationPreferences` 继续作为唯一设置模型；页面只编辑副本，点击保存或切换开关后调用 `NotificationCoordinator.requestPermissionAndUpdate`。协调器保存设置、校验权限、取消旧排期、创建新排期，并通过 `NotificationAuditStore` 返回每日提醒状态。周报、月报、优惠、预算沿用现有稳定的 ID 和 payload，不引入服务器推送。

通知中心按“状态摘要 + 规则卡片 + 系统设置/诊断”分组。规则卡片提供 Switch 和时间/日期控件，关闭规则立即取消排期，权限未开时显示去设置入口。所有异步刷新在页面销毁后不再 setState。

## 验收标准

1. 修改任意规则的开关或时间后，旧排期被取消，新排期可在系统队列中查询到。
2. 权限关闭时不会伪报“已安排”，页面显示待授权状态。
3. 每日、周报、月报、优惠规则均能从 UI 修改并持久化。
4. 诊断页能显示权限、队列数量，并可触发即时/15 秒定时测试。
5. Flutter 与后端现有测试全部通过；Android APK 构建成功并完成可执行的设备验证或明确记录设备未连接。
