# 小满记账磁吸流星导航设计

## 1. 目标与范围

本设计替代 `2026-09-15-meteor-navigation-and-completion-design.md` 中的“轨道余辉”视觉方案，但保留其页面跟手、可打断、边缘阻尼、触感反馈和性能要求。

本轮先在 Remotion 中制作可逐帧审查的磁吸流星动效，再将确认后的参数映射到 Flutter。范围仅包括底部导航与相邻页面切换，不修改业务页面、导航信息架构或应用主题。

成功标准：用户能立即辨认出“高速能量核留下拖尾并被目标图标吸收”，而不是发光进度条、单个光点或持续粒子装饰。

## 2. 设计原则

- **即时响应：** 手指开始移动的第一帧，页面、能量核和短尾迹同时响应。
- **连续可打断：** 点击、拖动、甩动和反向操作都从当前状态继续，不重播固定动画。
- **物理可信：** 速度决定尾迹长度，目标图标产生磁吸弯曲，落点产生压缩与回弹。
- **内容优先：** 慢速操作只有克制短尾；只有快速甩动才出现残影和少量光屑。
- **单一运动源：** 页面位移、导航进度、流星轨迹、图标状态和震动都读取同一个连续页索引及速度。

## 3. 视觉构成

### 3.1 能量核

能量核为横向压缩的椭圆亮点，不使用普通圆形光点。基础尺寸约为 `8×5px`，高速时沿运动方向拉伸至 `12×4px`。中心接近白色，外层使用当前主题强调色；光晕范围受限，不覆盖导航标签。

### 3.2 时间尾迹

尾迹不是固定渐变条，而是最近 `100–160ms` 位置历史的可视化：

- 主尾记录最近轨迹，清晰、窄、亮。
- 余辉记录更早轨迹，更宽、更透明。
- 两到三个残影只在释放速度达到阈值时出现。
- 光屑数量限制为 `0–3`，从高速轨迹中脱落并快速衰减，不常驻、不随机飘浮。

尾迹长度由速度连续映射。慢拖约 `18–32px`，普通切换约 `36–64px`，快速甩动上限约为单个导航单元宽度的 `1.15` 倍。反向操作时旧方向尾迹自然消散，新方向尾迹立即生成。

### 3.3 磁吸落点

接近目标图标的最后 `18%` 路程进入磁吸阶段：轨迹向目标图标中心轻微弯曲，能量核加速收束。命中时依次发生：

1. 能量核被目标图标吸收。
2. 图标沿水平方向压缩约 `4%`。
3. 图标以低过冲弹簧回到正常尺寸。
4. 一圈低透明度光波在 `100–140ms` 内消失。

落点不使用烟花、粒子雨或持续闪烁。

## 4. 交互与运动模型

### 4.1 手势输入

页面支持点击导航和内容区左右滑动。拖动期间不应用缓动，页面与手指保持一比一关系。首尾页向外拖动使用 `0.28` 阻尼。

松手时满足任一条件即切换一页：位移超过页面宽度 `18%`，或水平速度超过 `650px/s`。一次甩动默认最多跨一页，避免内容失去空间连续性。

### 4.2 状态输入

运动系统只接收以下输入：

- `continuousPage`：连续页面索引。
- `velocityPxPerSecond`：经过低通滤波的水平速度。
- `targetPage`：当前吸附目标。
- `isDragging`：是否直接操控。
- `reduceMotion`：系统减少动态效果设置。

所有视觉输出都由这些输入推导，不维护独立、容易失步的动画状态。

### 4.3 触感反馈

每次跨过相邻页面中心线触发一次轻触反馈，同一手势内同一中心线只触发一次。点击导航时在磁吸命中帧触发。回弹到原页不追加震动。

## 5. Remotion 原型架构

Remotion 原型使用 `useCurrentFrame()` 和 `interpolate()` 驱动，不使用 CSS `transition`、`animation` 或无限关键帧。

- `GestureTimeline`：生成慢拖、快速甩动、反向和边缘阻尼四段演示数据。
- `MeteorHistory`：保存并采样最近若干帧的位置历史，生成主尾与余辉。
- `MagneticTarget`：计算接近目标时的弯曲、压缩和回弹。
- `NavigationScene`：同时渲染页面、导航栏、流星和图标状态。
- `ComparisonComposition`：同屏展示旧方案与磁吸流星，避免只看参数无法判断差别。

原型必须至少提供慢拖、快甩、途中反向和命中吸收四个可拖动时间段。Remotion 只负责确定视觉与时序，最终实时手势仍由 Flutter 实现。

## 6. Flutter 落地边界

Flutter 使用单一导航运动控制器输出连续页索引和速度。页面容器、底部导航和 `CustomPainter` 共享该控制器。轨迹历史使用固定长度环形缓冲区，禁止逐帧创建无界粒子列表。

绘制层放入独立 `RepaintBoundary`。页面保持缓存，不因切换重复创建。动画仅改变 Canvas 参数、`transform` 和 `opacity`；不使用大面积 `BackdropFilter`，不逐帧修改 `width`、`left` 或 `top`。

减少动态效果模式下关闭光屑、残影、弯曲和扩散环，仅保留短尾、页面切换与选中颜色变化。

## 7. 异常与降级

- 速度采样异常或时间间隔为零时，速度回退为零，不产生超长尾迹。
- 连续掉帧时先关闭光屑，再缩短余辉采样窗口；页面跟手优先级最高。
- 动画被新手势打断时，立即采用新输入，不等待旧动画结束。
- 页面正在加载时仍允许导航跟手，但目标页面显示现有加载状态，不能冻结手势。

## 8. 验证与验收

### Remotion 验收

- 单帧检查能量核、主尾、余辉和磁吸目标的层级。
- 逐帧检查反向操作，旧尾迹衰减且新尾迹同帧生成。
- 验证所有运动由帧驱动，代码中不存在 CSS 动画和永久循环粒子。
- 渲染短视频确认 Studio 预览与导出结果一致。

### Flutter 验收

- 点击五个入口、慢拖、快甩、途中反向、首尾阻尼均可完成。
- 页面、导航、流星和震动不失步。
- Android 16 的 60Hz 与高刷新率模式连续操作无明显卡顿。
- 快速重复点击和手势中断不会闪回旧入口。
- 开启减少动态效果后仍能清楚辨认当前页面。

## 9. 明确不做

- 不复制任何厂商的具体视觉资产或系统动画。
- 不增加常驻星空、粒子雨、背景流光或音效。
- 不让流星跨越多个页面后继续自动播放。
- 不在本轮修改导航项目数量、业务页面布局或主题色系统。
