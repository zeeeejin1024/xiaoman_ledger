# 小满记账 5.9.0 基础界面一致性设计

## 1. 范围

版本 `5.9.0+14` 只处理四项基础改动：

1. 六套主题在所有底栏缓存页、路由页面和常用弹层中同步切换。
2. 底部导航删除“钱包”，从六项缩减为五项。
3. 首页标题固定，副标题通过独立“更改”入口编辑。
4. “我的”页面扩大个人资料编辑入口的命中范围。

本版本不实现钱包新数据模型、截图类别选择、真实语音、智能报告、流星导航和通知重构。

## 2. 页面结构

底部导航索引调整为：

| 索引 | 页面 |
|---:|---|
| 0 | 首页 |
| 1 | 统计 |
| 2 | 存钱 |
| 3 | 流水 |
| 4 | 我的 |

钱包页面继续保留，用户从首页“我的钱包”卡片进入。通知 payload 中的 `wallet` 路由继续有效，避免破坏旧通知。

## 3. 主题同步

根 `MaterialApp` 继续监听 `AppColors.notifier`，系统栏继续由 `AppSystemUi` 同步。新增统一的页面主题边界：缓存页与路由页在读取静态 `AppColors` getter 的视觉根节点使用 `AppThemeBuilder`。

底栏五个缓存页：首页、统计、存钱、流水、我的。首页当前已有主题边界；其余四页补齐。钱包、周报、月报、设置、语音和常用编辑弹层也补齐，以确保从“我的”页切换主题时当前页面、返回后的缓存页面和随后打开的路由页面颜色一致。

主题通知只触发 widget 重建，不调用 `_load()`、不更改状态对象 key、不清空滚动位置。测试通过 API 调用计数和 State 标识验证这一点。

## 4. 首页文案编辑

首页头部显示：

```text
小满记账
今天也留一点余地  更改
```

- 主标题不再读取或写入 `app_title`，也没有点击手势。
- 副标题读取新键 `home_subtitle`，默认值为“今天也留一点余地”。
- “更改”使用文字按钮，具有至少 48×48 的命中范围。
- 编辑弹层展示实时字数，最大长度 16；输入为空或全为空格时保存默认文案。
- 旧 `app_title` 偏好不删除，避免不可逆数据清理；新界面不再使用它。

## 5. 个人资料命中范围

头像区整行通过 `InkWell` 或 `GestureDetector(behavior: HitTestBehavior.opaque)` 响应打开个人资料。头像本身仍可单独更换头像，但其命中范围不得阻断整行其他区域。右侧箭头视觉尺寸保持 22，不单独承担唯一入口。

个人资料弹层的“完成”按钮和其他小型编辑入口使用至少 48×48 的约束。只扩大透明命中区域，不放大文字或图标。

## 6. 错误与状态处理

- 读取副标题失败时显示默认值。
- 保存副标题失败时保留编辑弹层并提示“保存失败，请重试”。
- 主题切换使用已持久化方案作为唯一状态，不在页面内部保存第二份颜色状态。
- 删除底栏钱包后，当前索引映射必须原子调整，避免旧索引 3 错误打开流水或钱包。

## 7. 测试和验收

先写失败测试，再实现：

- 导航只有五项且标签顺序正确，不包含“钱包”。
- 首页主标题不可点击，副标题只有“更改”按钮能打开编辑器。
- 副标题最多 16 字，空白保存恢复默认文案，重新创建页面后仍能读取。
- 切换主题后，统计、存钱、流水、我的和钱包页面的背景、卡片与文字同步变化。
- 主题切换不重新触发页面数据加载，不丢失懒加载页面状态。
- 个人资料整行和“完成”按钮命中范围至少 48×48。
- 现有全部 Flutter 测试通过，发布构建成功。
- 在 Android 16 实机完成浅色到极夜、极夜到未满之圆的双向测试，并截图首页、统计、存钱、流水、我的和钱包。
