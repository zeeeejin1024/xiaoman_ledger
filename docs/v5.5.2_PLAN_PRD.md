## 二、修复方案详细设计

### 问题 1：OCR 无法识别（🔴 最高优先级）

**根因链路**：
```
.env 文件存在 → 但无代码加载它 → QWEN_API_KEY="" → parse_receipt() 直接 return [] → "未能识别消费信息"
```

**修复方案：引入 python-dotenv**

| 改动文件 | 改动内容 |
|----------|----------|
| `backend/requirements.txt` | 添加 `python-dotenv` |
| `backend/app/main.py` | 顶部添加 `from dotenv import load_dotenv; load_dotenv()` |
| 后端服务器 | 重新部署后需要 `pip install python-dotenv` |

**同时影响**：`SECRET_KEY`、`DATABASE_URL`、`QWEN_API_KEY`、`XUNFEI_*` 等所有环境变量都会正确加载。

### 问题 2：自定义分类无法删除

**当前状态**：
- 后端 `categories.py`：只有 GET + POST，无 DELETE
- 前端 `category_api.dart`：只有 `getCategories()`，无删除方法
- 前端 `add_record_sheet.dart`：分类 UI 无删除交互

**修复方案：三层全链路实现**

#### 2a. 后端 - 添加 DELETE 端点

```python
# categories.py 新增
@router.delete("/{category_id}")
def delete_category(category_id: int, db: Session = Depends(get_db)):
    cat = db.query(Category).filter(Category.id == category_id).first()
    if not cat:
        return error(404, "分类不存在")
    if cat.is_system:
        return error(403, "系统预设分类不可删除")
    # 删除子分类
    db.query(Category).filter(Category.parent_id == category_id).delete()
    db.delete(cat)
    db.commit()
    return success(message="已删除")
```

#### 2b. 前端 API - 添加删除方法

```dart
// category_api.dart 新增
static Future<ApiResponse<dynamic>> deleteCategory(int id) async {
  final response = await _client.delete('/categories/$id');
  return ApiResponse.fromJson(response.data, null);
}
```

#### 2c. 前端 UI - 长按删除自定义分类

在 `add_record_sheet.dart` 的子分类 `GestureDetector` 上添加 `onLongPress`：
- 长按弹出确认对话框
- 仅对 `isSystem == false` 的分类显示删除选项
- 删除后刷新分类列表

**约束**：
- 系统预设分类（`is_system=True`）不可删除
- 删除根分类时同时删除其下所有子分类
- 如果分类下已有记账记录，提示用户确认

### 问题 3：GitHub 链接不可点击

**当前代码**（about_page.dart 第 96 行）：
```dart
_infoRow('GitHub', 'github.com/zeeeejin1024/xiaojia_ledger'),  // 纯文本
```

**修复方案**：改为 `_linkRow`，添加跳转逻辑：
```dart
_linkRow(Icons.code_rounded, 'GitHub 仓库', () => _launchUrl('https://github.com/zeeeejin1024/xiaojia_ledger')),
```

### 问题 4：帮助中心/用户协议无法打开

**当前问题**：
- 用户协议：`https://xiaoman.app/terms` → 域名不存在
- 帮助中心：`https://xiaoman.app/help` → 域名不存在
- `launch()` API 已废弃

**修复方案**：

| 链接 | 修复方式 |
|------|----------|
| 隐私政策 | 保持不变（华为云链接有效） |
| 用户协议 | 改为 GitHub 上的协议文件，或使用有效的华为云协议链接 |
| 帮助中心 | 改为 GitHub Wiki 或 App 内帮助页面 |
| 给我们评分 | 移除 Google Play 链接（国内不可用），改为"分享给朋友" |
| `_launchUrl` 方法 | 改用 `launchUrl(Uri.parse(url))` 替代废弃的 `launch(url)` |
